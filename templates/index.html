Scientific Architecture

How the Predictive Pipeline Operates

1. Trace Digitization
Computer-vision algorithms scan vertical pixel columns to convert 2D static plots into continuous 1D voltage timeseries.
2. QRS Peak Detection
NeuroKit2 QRS filtering pinpoints ventricular depolarizations, measuring precise RR interval dynamics across beats.
3. 90 HRV Biomarkers
Computes time-domain (RMSSD, SDNN), spectral (LF/HF ratio), and non-linear complexity metrics (Poincaré & entropy).
4. Random Forest
Ensemble decision trees evaluate the scaled feature vector against an optimized 0.38 decision boundary to flag pre-arrest signals.
